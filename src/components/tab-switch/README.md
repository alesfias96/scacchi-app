# src/components/tab-switch — Il selettore a schede

Due o più voci affiancate, una attiva, come un interruttore che scorre. Un clic cambia voce. Per i
lettori di schermo è un elenco di schede. Si usa in cima alla colonna di destra di «Gioca»,
«Tutor» e «Allenamento» per passare dalle schede della sezione al tutor.
