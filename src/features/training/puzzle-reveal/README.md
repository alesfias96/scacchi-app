# src/features/training/puzzle-reveal — La scheda "Soluzione"

Compare a puzzle finito. Mostra il **rating** dopo il puzzle e di quanto è cambiato (nel ripasso
non cambia), la **difficoltà** del puzzle, i suoi **temi** in italiano, la **soluzione** scritta come
nei libri e **perché funziona**: i fatti tattici che i rilevatori trovano nella posizione del
puzzle (forchette, pezzi in presa, inchiodature…). Passando il mouse su un fatto, la scacchiera
mostra le case coinvolte.

| File                      | Cosa fa       |
| ------------------------- | ------------- |
| `PuzzleReveal.tsx`        | Il componente |
| `PuzzleReveal.module.css` | I suoi stili  |

Sotto, «La combinazione»: la soluzione raccontata dal tutor con i suoi motivi uno dopo l'altro, le
schede dei motivi e i pulsanti «Allenati» per altri puzzle dello stesso tema.
