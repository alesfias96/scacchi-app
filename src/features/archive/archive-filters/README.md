# src/features/archive/archive-filters — I filtri dell'archivio

Due gruppi di scelte e una ricerca:

- **Avversario**: tutte, solo contro il computer, solo a due giocatori;
- **Esito**: tutte, vinte, perse, patte, in corso ("vinte" e "perse" riguardano le partite contro
  il computer);
- **Cerca un'apertura**: un testo da trovare nel nome (in inglese) o nel codice ECO.
