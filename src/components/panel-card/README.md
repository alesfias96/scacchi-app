# components/panel-card — La scheda dei pannelli

Una scheda con un titolo piccolo in alto, usata per tutte le informazioni
accanto alla scacchiera (situazione, mosse, comandi, ...). Usarla ovunque
garantisce che tutte le schede abbiano lo stesso aspetto in ogni tema.

| File                   | Cosa contiene                                               |
| ---------------------- | ----------------------------------------------------------- |
| `PanelCard.tsx`        | Il componente: titolo + contenuto                           |
| `PanelCard.module.css` | L'aspetto: fondo, margini, angoli arrotondati, titolo       |
| `PanelCard.test.tsx`   | Verifica che titolo e contenuto compaiano e siano collegati |
