# src/features/tutor/tutor-sections — Le parti della spiegazione

Mostra le parti della spiegazione del tutor (_La situazione_, _Cosa succede adesso_, _Il piano_,
_Da ricordare_) con le loro frasi, nella notazione scelta. Passando il mouse su una frase la
piccola scacchiera del tutor mostra le case coinvolte; se la frase ha una scheda della base di
conoscenza compare «Approfondisci». Lo stesso componente mostra anche cosa cambia con una mossa
provata.
