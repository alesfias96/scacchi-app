# knowledge/structures — Le strutture pedonali

La disposizione dei pedoni decide i piani. Il tutor riconosce le strutture più comuni guardando dove stanno i pedoni, per entrambi i colori, e mostra i piani di chi «ha» la struttura e del suo avversario.

Il formato delle schede è spiegato nel README della cartella `knowledge/`.
