# src/features/play/position-panel — La scheda "Situazione"

La scheda accanto alla scacchiera nella sezione Gioca che descrive la posizione
mostrata: chi deve muovere, quante mosse sono possibili, se il re è sotto scacco.
L'elenco delle mosse ha ora una scheda tutta sua (vedi `../move-list/`).
