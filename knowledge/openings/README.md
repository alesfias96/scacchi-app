# knowledge/openings — Le aperture

Le idee delle aperture più giocate, con i piani per il Bianco e per il Nero. Una scheda vale quando l'apertura riconosciuta (elenco di Lichess, nomi in inglese) appartiene alla famiglia indicata: ad esempio `Italian Game` vale anche per `Italian Game: Giuoco Piano`.

Il formato delle schede è spiegato nel README della cartella `knowledge/`.
