# src/features/notes/add-note-button — «Aggiungi un appunto»

Crea un appunto vuoto collegato alla posizione mostrata (e, se c'è, alla partita e alla mossa) e
apre la sezione «Appunti» su quell'appunto, pronto da scrivere. Si usa in «Gioca» e in «Analisi
partite».
