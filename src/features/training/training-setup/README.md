# src/features/training/training-setup — La scheda "Allenamento"

Le scelte con cui cominciare un puzzle: la **modalità** (calcolo, visualizzazione, "cosa
minaccia?", ripasso), quante **mosse** trovare (da 1 a 6, solo per calcolo e visualizzazione), i
**secondi** per memorizzare la posizione (solo nella visualizzazione), il **tema** e la
**difficoltà**. Il pulsante "Nuovo puzzle" (o "Ripassa") comincia il puzzle; se oggi non c'è
niente da ripassare il pulsante è spento.
