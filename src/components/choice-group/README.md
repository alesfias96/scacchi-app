# components/choice-group — Il gruppo di scelte a pastiglie

Un gruppo di piccoli riquadri cliccabili di cui se ne sceglie uno (ad esempio il colore o il
livello del computer nella finestra "Nuova partita"). Ogni riquadro ha un nome e, se serve, un
dettaglio sotto ("Circolo" · "1400 Elo"). Sotto ci sono normali pulsanti di scelta, quindi
funziona anche con la tastiera.

È la versione compatta di `option-group/`, che mostra anche un'anteprima disegnata.

| File                     | Cosa contiene                                     |
| ------------------------ | ------------------------------------------------- |
| `ChoiceGroup.tsx`        | Il componente                                     |
| `ChoiceGroup.module.css` | L'aspetto: griglia adattabile, scelta evidenziata |
| `ChoiceGroup.test.tsx`   | I test                                            |
