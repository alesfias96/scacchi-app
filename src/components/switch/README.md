# components/switch — L'interruttore

Un interruttore acceso/spento con la sua etichetta (ad esempio "Mostra analisi").
Sotto c'è una normale casella di spunta, quindi funziona anche con la tastiera (barra
spaziatrice) e con i lettori di schermo.

| File                | Cosa contiene                                          |
| ------------------- | ------------------------------------------------------ |
| `Switch.tsx`        | Il componente                                          |
| `Switch.module.css` | L'aspetto: la "pista" colorata e il pomello che scorre |
| `Switch.test.tsx`   | I test                                                 |
