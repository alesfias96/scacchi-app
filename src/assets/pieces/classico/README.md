# src/assets/pieces/classico — Pezzi "Classico"

Il set tradizionale "cburnett" in stile Staunton, quello dei libri di scacchi. Autore: Colin M. L. Burnett; distribuito con chessground con licenza GPL/BSD/GFDL.

Contiene 12 disegni SVG: `wK`, `wQ`, `wR`, `wB`, `wN`, `wP` (bianchi) e
`bK`, `bQ`, `bR`, `bB`, `bN`, `bP` (neri). Lettere: K re, Q regina, R torre, B alfiere, N cavallo, P pedone.
