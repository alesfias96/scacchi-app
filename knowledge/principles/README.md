# knowledge/principles — I principi generali

Regole semplici che valgono in quasi ogni partita (sviluppo, re al sicuro, centro…). Il tutor le richiama quando nella posizione c'è qualcosa di verificabile: ad esempio pezzi ancora a casa alla quinta mossa, o il re al centro all'ottava.

Il formato delle schede è spiegato nel README della cartella `knowledge/`.

| File                    | Scheda                        | Quando vale (riconosciuto da `crates/tutor/src/principles.rs`) |
| ----------------------- | ----------------------------- | -------------------------------------------------------------- |
| `development.toml`      | Sviluppare i pezzi            | `development`                                                  |
| `castle-king.toml`      | Mettere al sicuro il re       | `castle-king`                                                  |
| `center.toml`           | Il controllo del centro       | `center`                                                       |
| `open-file.toml`        | Le torri sulle colonne aperte | `open-file`                                                    |
| `bishop-pair.toml`      | La coppia degli alfieri       | `bishop-pair`                                                  |
| `king-activity.toml`    | Il re attivo nel finale       | `king-activity`                                                |
| `passed-pawn.toml`      | I pedoni passati              | `passed-pawn`                                                  |
| `trade-when-ahead.toml` | In vantaggio, semplifica      | `trade-when-ahead`                                             |
