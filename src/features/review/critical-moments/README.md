# src/features/review/critical-moments — La scheda «Momenti critici»

Le mosse che hanno cambiato la partita (al massimo cinque), in ordine. Per ognuna: la mossa
giocata con il suo simbolo, il giudizio a parole, la mossa migliore, cosa concedeva la mossa
giocata e cosa otteneva quella migliore. «Mostra sulla scacchiera» porta alla posizione prima
dell'errore, con le frecce delle due mosse.
