# src/assets/boards — Le scacchiere

Ogni immagine è una scacchiera intera (8×8 case), quadrata, 1024×1024 pixel.
Sono state **generate da zero** per questa app (venature e marmo creati al computer),
quindi non hanno vincoli di licenza esterni.

Il collegamento tra stile scelto e immagine è in `src/components/chessboard/themes/boards.css`;
il colore della cornice di ciascuna è in `src/styles/tokens.css`.

## Contenuto

| File          | Stile                                                   |
| ------------- | ------------------------------------------------------- |
| `noce.jpg`    | Noce: legno scuro e caldo                               |
| `acero.jpg`   | Acero: legno chiaro e luminoso                          |
| `rovere.jpg`  | Rovere: legno intermedio, il più classico (predefinito) |
| `marmo.jpg`   | Marmo: bianco venato e verde salvia                     |
| `ardesia.jpg` | Ardesia: grigio-blu opaco                               |
| `torneo.jpg`  | Torneo: colori piatti verde e crema                     |
