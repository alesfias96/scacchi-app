# src/app/app-layout — La struttura della finestra

Divide la finestra in due colonne: la barra laterale a sinistra (larghezza fissa)
e l'area di lavoro a destra, che occupa tutto lo spazio rimasto e scorre se il contenuto è lungo.

## Contenuto

| File                   | Cosa fa                                                                     |
| ---------------------- | --------------------------------------------------------------------------- |
| `AppLayout.tsx`        | Il componente: riceve la barra laterale e il contenuto della sezione aperta |
| `AppLayout.module.css` | La griglia a due colonne                                                    |
